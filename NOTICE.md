# Disclosure Boundary

This repository is a public research portfolio for 趋势过滤器 (Trend Filter).

Production Pine Script, exact formulas, calibrated settings, private test infrastructure, raw private data, and execution-specific rules are excluded.

The project was separated from the author's 波段过滤器 (WaveFilter) development process. The public record describes project scope and origin without publishing the private implementation.

Public descriptions and selected figures do not establish profitability, predictive accuracy, or cross-market statistical validity. No rights to private implementation material are granted by this documentation.
