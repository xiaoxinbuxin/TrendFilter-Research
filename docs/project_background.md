# Project Background

## From a shared project to separate chart roles

Trend Filter grew out of the author's work on 波段过滤器 (WaveFilter). As additional functionality was planned for the price chart, the main-chart work was separated into its own project rather than continuing to place every feature within the sub-chart indicator.

The project history is therefore a split within the author's own development process. The two projects share that origin while serving different chart roles.

## Selected milestone

The current milestone selected for this portfolio is **趋势 R3 (Trend R3)**. Earlier Trend Filter or TrendR2 material must not be presented as an R3 implementation audit or R3 test result.

## Relationship to the public WaveFilter record

[波段过滤器 / WaveFilter Research](https://github.com/xiaoxinbuxin/WaveFilter-Research) documents the sub-chart project. Its public synthetic notebook demonstrates an evaluation procedure on generated data; it does not implement or validate Trend R3.

Separate repositories help readers understand scope and inspect each project's evidence. Shared origins and shared development work should be disclosed when describing both projects in a portfolio.
