# Project Background

## Research scope

Trend Filter studies price-chart context and the statistical characterization of observed swing magnitude. Trend-state bands and contextual labels describe local price conditions, while swing percentiles place normalized movement sizes in the context of historical same-direction swings.

The research question is how to communicate the size and context of a developing move without treating a descriptive statistic as a forecast. A historical magnitude distribution provides a reference for comparison; it does not determine the size of the next move.

## Selected milestone

The current milestone selected for this portfolio is **Trend R3**. Earlier Trend Filter or TrendR2 material must not be presented as an R3 implementation audit or R3 test result.

## Related public project

[WaveFilter Research](https://github.com/xiaoxinbuxin/WaveFilter-Research) documents a sub-chart wave and market-state representation. Trend Filter presents context in price coordinates. Each project has its own evidence boundaries; the WaveFilter synthetic notebook does not implement or validate Trend R3.
